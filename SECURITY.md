# Security Policy

## Supported versions

Security and robustness fixes are primarily evaluated against the latest gp-series release candidate or stable release in this repository.

## Reporting a security issue

Do not publish credentials, private hostnames, API keys, tokens, passwords or complete configuration files containing secrets in a public GitHub issue.

For a suspected security issue in this repository, open a GitHub issue only if the report can be safely described without sensitive data. Clearly mark it as a security-related report and provide the minimum information needed to reproduce the problem.

If sensitive material would be required to demonstrate the issue, contact the repository maintainer privately through an appropriate contact channel listed on the maintainer's GitHub profile rather than posting the sensitive material publicly.

## Diagnostic data

Developer traces can contain timestamps, device state, packet metadata and local file paths. Review diagnostic bundles before publishing them and remove unrelated sensitive information.
